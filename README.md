# Dear-Data-100
The Burgundy Frequency Matrix
Over the Autumn and Winter period, I recorded every instance in which individuals wore a burgundy clothing item during my commute and time in university setiings.
As someone whose favourite colour is burgundy, this project helps me explore the boundary between personal style identity, shifting fashion trends and when overconsumption in a trend reaches too far.

The data was collect daily on my phone's notes app and transferred into csv format.
Each row tracks:
1. Personal Match: Was I wearing a burgundy item that day?
2. Item Category: Grouped into Clothes (C), Accessories (A), or Hijab(H)
3. Shade Value: Ranging from 1-3 lightest to darkest.
4. Location: Classified by Lectures (L), Commuting (C), or Social settings (S).

Visual Encoding Key for my sketch:
- Timeline(X-Axis):Chronological progression from Left (Week 1) to Right (Week 10).
- Spatial Mapping (Y-Axis):Divided into three horizontal areas based on Location (L top, C middle, S bottom).
- Geometric Primitives:Clothes appear as Circles, Accessories as Triangles, and Hijabs as Squares.
- Visual Chaos vs. Fusion :Multiple items observed on the same individual stack directly on top of each other. Incoherent outfit choices create a fragmented, overstimulating geometry. Perfect color matches fuse seamlessly into a singular, brand-new shape.
- The Self-Anchor: Items observed on days where I am also wearing burgundy are rendered with a distinct structural border outline. The default location will be the commute since that when I start recording data.
